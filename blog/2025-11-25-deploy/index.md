기존 배포 방식은 다음과 같습니다.

### 서버
1. 코드 수정
업데이트할 내용에 따른 코드를 수정합니다.

2. jar 파일 생성
수정된 코드를 기반으로 jar 파일을 빌드합니다.

3. jar 파일 전송
서버에 jar 파일을 전송합니다.

4. jar 파일 실행
서버에서 jar 파일을 실행합니다.
   
### 안드로이드
1. 코드 수정
업데이트할 내용에 따른 코드를 수정합니다.

2. 버전 변경
버전을 변경합니다.

3. aab 파일 생성
수정된 코드를 기반으로 aab 파일을 빌드합니다.

4. 버전 배포
빌드된 aab 파일로 콘솔에서 새로운 버전을 배포합니다.
